Experimental Blender iPad cooperative-startup candidate

This full package contains a NEW native engine. Replace all files in the
existing WorldWideWeb Blender folder, including blender-core.js, .wasm and
.data. Keep serving the same localhost address/port to retain saved projects.
Install using http://localhost:8080/ipad-update.html, then close all Blender and
updater tabs/Home Screen windows before reopening http://localhost:8080/.
Press Start once. The statistics panel identifies v8 and counts native yields.

Native shader translation can now yield between shaders during the initial
viewport frame, allowing browser timers/painting to run. Canvas presentation
refreshes the acquired surface after these yields. Input and resize callbacks
cannot re-enter native initialization while it is suspended. Yielding stops
after the first content frame; no render functionality is disabled.

The package must pass native suspension, canvas pixel/ownership, editor,
modeling, rendering and recovery checks before delivery. These tests do not
establish physical iPad acceptance. An individual translation or CPU setup
stage can still block, and this does not guarantee a successful iPad launch.
If the device becomes unresponsive, close Blender rather than repeatedly
restarting it. Reopen without pressing Start and download the device report.
Do not clear Safari website data; export project backups when available.

GPL-3.0-or-later. Corresponding source and dependency notices accompany the
accepted build as a separate artifact on the same GitHub Actions run page.
